# Grocery Store Roles

## Costco
Use for:
- milk
- eggs
- bulk protein when clearly worthwhile
- recurring snack staples
- household stock-ups
- sparkling water / drinks when value is strong
- detergent / paper / pantry bulk buys

Rules:
- prefer only items clearly worth the in-store trip
- verify likely inventory with Costco Same-Day / Instacart when useful
- use in-store receipts as the better price truth when available
- do not assume Same-Day price equals warehouse price

## Aldi
Use for:
- cheap staples
- bread / buns / bagels
- produce
- yogurt / simple dairy
- flexible meal ingredients
- lower-cost pantry fill-ins

Rules:
- good for both staple and meal-plan expansion
- more automation-fragile than Walmart
- if browser automation is annoying, in-store fallback is acceptable

## Walmart
Use for:
- brand-specific items
- specialty cleanup buys
- missing items from Aldi/Costco
- items where Jonathan's real preference matters more than raw price

Rules:
- most automation-friendly store so far
- often the cleanup store rather than the primary savings store
- use as the baseline comparator when evaluating savings
