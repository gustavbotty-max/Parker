# Mac Second Body Starter Package

This bundle is meant to bootstrap the Mac as Gustav's helper machine / second body.

## Intent
- One assistant identity
- One soul
- One long-term memory spine
- Multiple machines with different jobs

## Suggested use
1. Unpack into a temporary folder on the Mac
2. Review files before merging into the Mac OpenClaw workspace
3. Keep the VPS as the canonical data/memory hub for now
4. Use the Mac for browser automation, retail-site pricing, and trusted local sessions

## Included
- Identity/context files
- Grocery pricing/burn-rate datasets and helper scripts
- Relevant recent memory files
- Agent docs / orchestrator files
- Mac-specific host notes

## Not included
- browser cookies/profiles
- node_modules
- secrets archives
- unrelated static-site clutter
- full OpenClaw runtime state

- Verify `openclaw status` and gateway
- Enable Tailscale (no exit node by default)
- Install/prepare browser relay path
- Merge needed files into the Mac workspace
- Test Costco/Instacart local browser control
